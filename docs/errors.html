Errors

Every error code, its meaning, exit code and remediation.

Stable codes. str(error) gives the message and the remediation. Exit codes: 0 ok, 1 user error, 2 remote error, 3 refused for safety.

CodeMeaningExitRemediation
JADE100not configured1Run jade init, or set JADE_CONFIG to a jade.config.yaml.
JADE101bad token1The server refused the token. Make a new one and store it: jade secret set <name>.
JADE102legacy query-string authentication refused3This Vault accepts ?token= in URLs. Update Jade Vault to 2.18.3 or later. Only for diagnosis: --accept-legacy.
JADE103credential refused3Base refused the task credential (revoked or expired). The task stops; it is not retried. Start the task again.
JADE104secret store unavailable1Install keyring (pip install keyring), or allow a 0600 file with --accept-file-secrets.
JADE105missing secret1Store it with jade secret set <name>, or set the environment variable JADE_SECRET_<NAME>.
JADE200cannot reach the target2Check the URL in jade.config.yaml and that the server is running (jade doctor).
JADE201MCP protocol mismatch2The server speaks another MCP protocol version. Update the server or the toolkit.
JADE202remote error2The target answered with an error; the message says which.
JADE203incompatible version2The target's version is outside what STACK.md allows. Upgrade the target or the toolkit (jade doctor).
JADE204timed out2The call took longer than its timeout. Pass timeout= / --timeout, or check the target.
JADE205idempotency conflict2The same idempotency key was used with other arguments. Use a new key for a new call.
JADE300approval required3Allow it in jade.config.yaml under approvals, or confirm interactively.
JADE301denied by approvals3A deny rule in jade.config.yaml matches. Deny wins; change the rule to allow it.
JADE302unsafe without confirmation3Destructive or unknown operations need a person to confirm, or --yolo (logged).
JADE303playbook not approved3Review it, then jade playbook approve <name>. Any edit needs a new approval.
JADE400invalid configuration1Fix jade.config.yaml at the place the message names (jade config show).
JADE401invalid playbook1Fix the playbook at the place the message names (jade playbook check <name>).
JADE402invalid site spec1Fix the site spec at the place the message names (jade site check).
JADE403unknown tool1The target has no such tool. List them: jade base tools.
JADE404ambiguous tool1More than one target has this tool. Name the target.
JADE405not found1Check the name; list what exists with the matching list command.
JADE406generated files are stale1Run python build/build.py and commit the result.
JADE500doctor failed1Run jade doctor and fix what it reports, or pass --force to go on anyway.
