Jade Agent Stack

One Python package to drive the Jade repositories: Vault (control plane), Agent Base (resource plane), Agent Kit (the embeddable subset of Vault) and Agent UI/UX (presentation). It is a client, not a fork, and it needs the network to reach them.

pip install jade-agent-stack
jade init && jade doctor
jade site new "Acme AI" --template saas && jade site build && jade site preview

People read these pages; agents read the Markdown and llms.txt, or ask jade docs search.

Try the live demo: a whole AI business (sign-up, plans and checkout, account with usage and API keys, a waitlist, a product list, a chat) built from one YAML file, with a pretend backend that runs in your browser.
