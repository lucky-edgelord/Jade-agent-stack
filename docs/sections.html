Sections

Every page section and its parameters.

The building blocks of a page. In a spec: - hero or - {type: hero, title: …}. Every section also takes id and class.

nav

The top bar: the site's name, links to its pages, a theme switch and, with a backend, Sign in.

ParameterTypeDefaultMeaning
brandstringname shown (default: the site name)
linkslistlinks [{"label", "href"}] (default: every page with nav = true)
ctaobjecta button {"label", "href"}
theme_togglebooltrueshow the light/dark switch

hero

The opening: a big title, a line under it, buttons and an optional image.

ParameterTypeDefaultMeaning
titlestringheadline (default: the site name)
subtitlestringone or two sentences (default: the site tagline)
eyebrowstringsmall text above the title
buttonslist[{"label", "href"}] (first is primary)
imagestringan image URL or path
alignstring"center"center | left
- {"type": "hero", "title": "Embeddings for every app", "subtitle": "One API, fair prices.", "buttons": [{"label": "Start free", "href": "/account"}]}

features

A grid of features: an icon (emoji or short text), a title and a sentence each.

ParameterTypeDefaultMeaning
titlestringheading
subtitlestringline under the heading
items requiredlist[{"icon", "title", "text"}]
columnsint3columns on wide screens
- {"type": "features", "title": "Why us", "items": [{"icon": "\u26a1", "title": "Fast", "text": "Answers in milliseconds."}]}

steps

Numbered steps (how it works).

ParameterTypeDefaultMeaning
titlestring"How it works"heading
items requiredlist[{"title", "text"}]

stats

Big numbers with labels.

ParameterTypeDefaultMeaning
items requiredlist[{"value", "label"}]
titlestringheading

pricing

Plans. With a backend: the live plans and Subscribe buttons (Stripe Checkout). Without: the plans you list.

ParameterTypeDefaultMeaning
titlestring"Pricing"heading
subtitlestringline under it
currencystring"USD"currency code
planslistfor a static site: [{"name", "price", "features": [...], "button": {"label","href"}}] (default: backend.plans)

Needs the backend modules: gateway.

- {"type": "pricing", "title": "Pricing"}

auth

Sign in, create an account, reset a password (needs a backend). After signing in, go to next.

ParameterTypeDefaultMeaning
titlestringheading above it
nextstringwhere to go after signing in, e.g. /account

account

The signed-in user's plan, usage, billing and API keys; signed out, a sign-in form (needs a backend).

ParameterTypeDefaultMeaning
titlestring"Your account"heading
currencystring"USD"currency code

Needs the backend modules: gateway.

chat

An AI chat. mode gateway: the backend's models for signed-in users. mode ollama: the visitor pastes an Ollama Cloud key. mode demo: a scripted demo.

ParameterTypeDefaultMeaning
titlestringheading
modestring"gateway"gateway | ollama | demo
modelstringmodel name (gateway: one of backend.models)
systemstringsystem prompt
greetingstring"How can I help?"empty-state heading
suggestionsliststarter prompts
heightstring"70vh"CSS height
toolsboolfalsegive the model the kit's workspace tools (files, shell)
repliesobjectdemo mode: {"keyword": "reply"}; "*" for anything else

Needs the backend modules: gateway.

- {"type": "chat", "model": "house-chat", "suggestions": ["What can you do?"]}

form

A form that saves to a backend collection (waitlists, contact forms, signups). The collection must let anyone create.

ParameterTypeDefaultMeaning
collection requiredstringcollection name
titlestringheading
textstringa line under it
fields requiredlistfield specs "name:type!" (type: text, email, number, url, textarea, checkbox; ! = required) or {"name","label","type","required"}
submitstring"Send"button label
successstring"Thank you! We got it."shown after sending
- {"type": "form", "collection": "waitlist", "fields": ["email:email!", "company:text"], "submit": "Join the waitlist"}

records

Cards listing records of a public backend collection (products, posts, team, …).

ParameterTypeDefaultMeaning
collection requiredstringcollection name (its list rule must allow the visitor)
titlestringheading
title_fieldstring"title"field shown as the card title
text_fieldstringfield shown as text
image_fieldstringfile field shown as the image
price_fieldstringfield shown as a price
filterstringPocketBase filter
sortstringsort, e.g. title or -price (-created needs a created field)
limitint12how many
emptystring"Nothing here yet."shown when there are none
- {"type": "records", "collection": "products", "title_field": "title", "text_field": "description", "price_field": "price"}

faq

Questions and answers that open and close.

ParameterTypeDefaultMeaning
titlestring"Questions"heading
items requiredlist[{"q", "a"}] (answers may use markdown)

cta

A call to action: a heading, a line and a button, on a coloured band.

ParameterTypeDefaultMeaning
title requiredstringheading
textstringa line
buttonobject{"label", "href"}

markdown

Text written in markdown (or a .md file next to jade.toml).

ParameterTypeDefaultMeaning
textstringmarkdown
filestringa markdown file, relative to jade.toml
narrowbooltruea reading width

gallery

A grid of images with captions.

ParameterTypeDefaultMeaning
titlestringheading
images requiredlist[{"src", "alt", "caption"}] or URLs
columnsint3columns

code

A code block with copy and highlighting.

ParameterTypeDefaultMeaning
titlestringheading
langstring""language
code requiredstring""the code

surface

UI from a Jade surface spec (components, data, actions), e.g. a calculator, a dashboard or a quiz.

ParameterTypeDefaultMeaning
titlestringheading
specobjecta surface spec: {root, components, data} (see the UI/UX catalog)
filestringa saved surface spec (YAML or JSON), relative to jade.site.yaml: reuse a design instead of rebuilding it
namestringsurface name (for agents and actions)

html

Your own HTML, as it is (an escape hatch).

ParameterTypeDefaultMeaning
html requiredstring""HTML

footer

The bottom of the page: a line of text and links.

ParameterTypeDefaultMeaning
textstringtext (default: © the site name)
linkslist[{"label", "href"}]
