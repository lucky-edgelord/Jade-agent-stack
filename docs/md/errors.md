# Errors

Stable codes. `str(error)` gives the message and the remediation. Exit codes: 0 ok, 1 user error, 2 remote error, 3 refused for safety.

| Code | Meaning | Exit | Remediation |
| --- | --- | --- | --- |
| `JADE100` | not configured | 1 | Run `jade init`, or set JADE_CONFIG to a jade.config.yaml. |
| `JADE101` | bad token | 1 | The server refused the token. Make a new one and store it: `jade secret set <name>`. |
| `JADE102` | legacy query-string authentication refused | 3 | This Vault accepts ?token= in URLs. Update Jade Vault to 2.18.3 or later. Only for diagnosis: --accept-legacy. |
| `JADE103` | credential refused | 3 | Base refused the task credential (revoked or expired). The task stops; it is not retried. Start the task again. |
| `JADE104` | secret store unavailable | 1 | Install keyring (`pip install keyring`), or allow a 0600 file with --accept-file-secrets. |
| `JADE105` | missing secret | 1 | Store it with `jade secret set <name>`, or set the environment variable JADE_SECRET_<NAME>. |
| `JADE200` | cannot reach the target | 2 | Check the URL in jade.config.yaml and that the server is running (`jade doctor`). |
| `JADE201` | MCP protocol mismatch | 2 | The server speaks another MCP protocol version. Update the server or the toolkit. |
| `JADE202` | remote error | 2 | The target answered with an error; the message says which. |
| `JADE203` | incompatible version | 2 | The target's version is outside what STACK.md allows. Upgrade the target or the toolkit (`jade doctor`). |
| `JADE204` | timed out | 2 | The call took longer than its timeout. Pass timeout= / --timeout, or check the target. |
| `JADE205` | idempotency conflict | 2 | The same idempotency key was used with other arguments. Use a new key for a new call. |
| `JADE300` | approval required | 3 | Allow it in jade.config.yaml under approvals, or confirm interactively. |
| `JADE301` | denied by approvals | 3 | A deny rule in jade.config.yaml matches. Deny wins; change the rule to allow it. |
| `JADE302` | unsafe without confirmation | 3 | Destructive or unknown operations need a person to confirm, or --yolo (logged). |
| `JADE303` | playbook not approved | 3 | Review it, then `jade playbook approve <name>`. Any edit needs a new approval. |
| `JADE400` | invalid configuration | 1 | Fix jade.config.yaml at the place the message names (`jade config show`). |
| `JADE401` | invalid playbook | 1 | Fix the playbook at the place the message names (`jade playbook check <name>`). |
| `JADE402` | invalid site spec | 1 | Fix the site spec at the place the message names (`jade site check`). |
| `JADE403` | unknown tool | 1 | The target has no such tool. List them: `jade base tools`. |
| `JADE404` | ambiguous tool | 1 | More than one target has this tool. Name the target. |
| `JADE405` | not found | 1 | Check the name; list what exists with the matching `list` command. |
| `JADE406` | generated files are stale | 1 | Run `python build/build.py` and commit the result. |
| `JADE500` | doctor failed | 1 | Run `jade doctor` and fix what it reports, or pass --force to go on anyway. |
