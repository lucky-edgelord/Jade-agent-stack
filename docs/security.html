Security

The threat model across Vault, Base, Kit, UI/UX and the toolkit, and what each defence covers.

Defences in the toolkit

DefenceWhere
Header-only auth; URLs with tokens are refused (client and jade serve)jade.http, jade.serve
A Vault that accepts ?token= is refused (JADE102)jade init, jade doctor, every Vault call
Secrets in the OS keyring; never in config, output, logs or errorsjade.secrets, jade.redact
Local approvals, deny wins, enforced before a call leavesjade.approvals
Destructive calls need a person (or a logged --yolo)harness
Playbook approvals bound to the file's hashjade playbook approve
Short-lived, least-privilege task credentialsBase 0.6 /api/agent/credentials
Idempotency keys on every mutationBase 0.6
A sandboxed expression language (no calls, imports or I/O)jade.playbook.template
Generated pages escape all text; markdown drops raw HTML and javascript: linksjade.site

Threats

ThreatWhat can happenWhat limits it
A malicious note in Vaultinstructions in a note steer the agentVault's approvals; Base scopes and task credentials bound what a steered agent can do; Base logs every call and refusal
A malicious web page fetched by the agentthe same, from the webthe same; in Vault, its own fetch approvals; no URL tokens to leak
A malicious MCP servertool descriptions or results that steer the agent; data exfiltrationVault approves MCP servers; in the toolkit, approvals per tool and target; credentials are per task and short
A stolen Vault token used against BaseVault's agent token is not a Base token; a Base token Vault holds can act within its scopestask credentials expire in minutes; revoking the agent ends them all; schema, hooks, settings are root-equivalent: give them sparingly
A compromised Base used against Vaultanswers that steer Vault's agent; false datatreat Base results as data, not instructions; approvals still apply in Vault and the toolkit
A leaked toolkit configURLs and approval rulesno secrets in it by design
A shared terminal loga token in a URL or headerURL tokens refused; --verbose redacts Authorization and registered secrets
